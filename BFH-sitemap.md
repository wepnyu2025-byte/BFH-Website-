## Navigation

## Section order and layout suggestion per page
Follow the section order in `BFH-content.md`. Suggested layout variety for Home:

1. Hero: large centered headline, hero image below or beside, button
2. Trust Introduction: white, centered text block
3. Six Areas: teal-50, sticky list (headline sticks left, items scroll right)
4. Community: split section, image + text
5. Live Sessions: floating rounded teal-700 panel
6. Products: three soft rounded cards
7. Member Benefits: white, centered statement with BF Benefits Card image
8. Certification: split section, text + image
9. Final CTA: floating rounded teal-800 panel, white headline, soft button

Backgrounds alternate white / teal-50 / dark teal to create separation without borders.
